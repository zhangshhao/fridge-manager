## 已知边界

- 首版需要联网，不支持离线业务数据副本或离线写入队列。
- 包装重量没有换算维护界面，不同维度单位直接拒绝转换。
- 忌口校验为已知名称/别名及文本约束，不是医疗级过敏原识别，需人工复核。
- 日历按月读取记录；常规列表接口每次最多 1000 餐，流水按 100 条分页。
- AI 并发为单 API 进程限制；当前部署固定一个 API 实例，扩容前需使用共享限额和并发存储。
- 导出、删除及恢复为管理员维护流程，没有公网下载入口。错误监控提供 JSON 日志、健康检查及备份回调；实际通知服务需在部署时配置。

本次结论：本机可运行版本及自动化验收已完成，生产上线及手机真机验收待资源准备。
